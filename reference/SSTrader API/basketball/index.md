title: Basketball
excerpt: >-
  Basketball reference data and fixtures, under `/basketball/...`. Same paths
  and response shapes

  as football, read from basketball's own data. Read-only. Includes so far:
  `statistics`, `odds`, and on the single fixture `squads`, `lineups`.


  Basketball ids are **not** football ids: a basketball league, team, fixture or
  season id can

  have the same number as an unrelated football one. Always call the basketball
  endpoints with

  basketball ids.
